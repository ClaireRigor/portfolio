# Clarizza Rigor Professional Portfolio

A responsive professional portfolio built with HTML, CSS, and JavaScript.

## Structure

- `index.html` — page structure and professional content
- `css/style.css` — visual design and responsive layout
- `js/script.js` — mobile navigation and dynamic footer year
- `TESTING.md` — Stage 5 testing checklist
- `images/` — place portfolio images here

## Local development

Open `index.html` directly in a browser or use the VS Code Live Server extension.

## Git workflow

After making changes:

```bash
git status
git add .
git commit -m "Update professional portfolio content"
git push
```

## Important security note

Do not commit passwords, API keys, access tokens, company credentials, confidential client information, or other secrets to this repository.
